## 2. 프로젝트 소개

이번 과제에서는 실습과제 #1에서 제작한 영화 보드의 데이터를 활용하여 자바스크립트로 영화 정보를 분석하는 프로그램을 구현했습니다.

내 인생 영화 5편과 일별 박스오피스 TOP 5를 합친 총 10편의 영화 데이터를 사용했습니다. 배열, 반복문, 조건문, 함수, 객체 배열을 활용하여 영화의 평균 평점, 최고 평점 영화, 개봉 연대별 영화 수, 누적 관객 수 등을 계산했습니다.

또한 TMDB API에서 현재 상영 중인 영화 데이터를 가져와 평균 평점과 평점 상위 5편을 분석했습니다.

## 5. 구현 내용

### Part A: 배열과 반복문

영화 10편의 제목, 평점, 개봉 연도, 누적 관객 수를 각각 배열에 저장하고 반복문과 조건문을 활용하여 분석했습니다.

- [x] A1. 영화 10편의 평균 평점 계산
- [x] A2. 최고 평점 영화 찾기
- [x] A3. 평점 8.0 이상 영화 수 계산
- [x] A4. 개봉 연대별 영화 수 계산
- [x] A5. 누적 관객 100만 명 이상 영화 찾기

### Part B: 함수와 객체 배열

영화 10편의 정보를 객체 배열 movies로 구성하고, 다양한 기능을 함수로 구현했습니다.

- [x] average() - 평균 평점 계산
- [x] best() - 최고 평점 영화 찾기
- [x] filterByRating() - 지정한 평점 이상의 영화 필터링
- [x] sortBy() - 지정한 속성을 기준으로 정렬
- [x] search() - 영화 제목 검색
- [x] formatNumber() - 숫자에 천 단위 쉼표 표시
- [x] yearsSince() - 개봉 후 지난 연도 수 계산
- [x] 웹페이지에 영화 분석 결과 3줄 출력

### Part C: TMDB 데이터 분석

TMDB의 now_playing API에서 가져온 JSON 응답을 tmdb.js에 저장하고 자바스크립트로 분석했습니다.

- [x] getList() - TMDB 응답에서 영화 목록 추출
- [x] averageBy() - 지정한 숫자 속성의 평균 계산
- [x] C1. 페이지 정보 출력
- [x] C2. 현재 상영 영화 평균 평점 계산
- [x] C3. 평점 상위 5편을 console.table()로 출력
- [x] C4. 영화 제목 검색 결과 수 출력

## 6. 자체 테스트 8개

## 7. 어려웠던 점과 해결 방법

### 1) 자바스크립트 코드를 작성하고 수정하는 과정

Part A, B, C를 진행하면서 코드가 점점 길어져 어느 위치에 새로운 코드를 추가해야 하는지 헷갈렸습니다. 특히 기존 함수를 수정하면서 다른 코드에 영향을 주지 않도록 하는 것이 어려웠습니다.

이를 해결하기 위해 코드를 Part A, B, C로 구분하고, 각 함수의 역할을 주석으로 표시했습니다. 또한 전체 코드를 정리하여 중복되는 부분을 수정하고, 한 파일에서 모든 기능이 실행되도록 구성했습니다.

### 2) 웹페이지 실행과 개발자 도구 사용

VS Code에서 HTML 파일을 실행하는 방법을 찾는 것이 어려웠습니다. Live Server가 설치되어 있었지만 실행 메뉴가 보이지 않아 처음에는 웹페이지를 확인하지 못했습니다. 또한 브라우저의 Console 위치를 찾는 데에도 어려움이 있었습니다.

이를 해결하기 위해 index.html 파일을 브라우저에서 직접 실행하고, F12를 눌러 개발자 도구의 Console을 열었습니다. 이를 통해 자바스크립트의 계산 결과를 확인하고 웹페이지에 출력되는 내용과 콘솔 결과의 차이를 이해할 수 있었습니다.

### 3) TMDB API 데이터와 영화 정보 활용

기존 영화 보드의 HTML에 작성된 영화 정보를 자바스크립트 배열과 객체 배열로 옮기는 과정이 어려웠습니다. 또한 TMDB API에서 가져온 JSON 데이터를 어떤 파일에 저장하고 어떻게 활용해야 하는지 처음에는 헷갈렸습니다.

이를 해결하기 위해 영화 10편의 제목, 평점, 개봉 연도, 관객 수를 data.js에 정리하고, TMDB API 응답 데이터를 tmdb.js에 저장했습니다. 이후 app.js에서 함수와 반복문을 활용하여 평균 평점, 최고 평점 영화, 관객 수, 현재 상영 영화 순위 등을 계산하도록 구현했습니다.
